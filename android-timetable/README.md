# 小交课表 Android

独立于根目录微信小程序的安卓课表应用。Android Studio 打开本目录即可预览和构建。最低 Android 8.0，包名 `io.github.cuimiles.xiaojiao`。

首次使用点「登录西交大教务网」，输入学号或手机号及密码；应用只在西交大官方 HTTPS 登录页自动填写，并读取已登录课表。首次成功导入后，账号密码通过 Android Keystore 的 AES-GCM 密钥加密后保存在应用私有存储，一年到期或学校确认登录失败时清除；刷新课表会自动登录。也可选择学校网页手动登录，这种方式不保存密码。「更多」可随时清除已存登录信息。WebView 在登录期间使用学校会话 Cookie，退出时清理 Cookie 和站点存储。刷新会保留手动添加的课程以及已有的颜色和备注。

课表主页横向展示周一至周日，左右滑动切换周次，点击左上角周次可快速选周；短屏可纵向滚动。课程区域不显示网格线，仅在日期行下保留浅分隔线。时间列展示每节课的开始和结束时间。顶栏依次是刷新、回到本周、新建课程和更多。默认使用浅蓝、浅绿、浅橙等柔和课程色；「更多 → 调色盘」选课后可在圆形色盘上拖动，实时预览并调节深浅与透明度，应用后同名课程一起更新。新建或编辑课程也可打开调色盘。右上角「更多」还支持导入小程序的 2026 秋季 JSON 课表，也可导出保留自定义颜色的安卓版备份（旧小程序暂不识别自定义色值）、打开校园网更新页、查看小红书主页并直接保存图片到系统相册。新建课程含体育课模板，可以修改星期、节次、周次、教师、教室、颜色、备注。点课程即可查看、编辑或删除。首次安装时课表为空，不导入个人数据。

本机已生成的签名包在 `dist/xiaojiao-timetable-0.5.0.apk`；`dist/sha256.txt` 是校验值。安装包目录被 Git 忽略。发布下一版前先在 `app/build.gradle.kts` 增加 `versionCode` 和 `versionName`，再运行 `python3 tools/build_release.py`。脚本会用 `JAVA_HOME`、`ANDROID_HOME` 和 Gradle 构建、验签，随后更新 `dist/`。首次构建会在当前用户的 `~/.local/share/xiaojiao-timetable/` 创建私有签名密钥。**妥善备份该密钥与 `signing.json`**：后续更新必须使用同一签名。源码和安装包都不包含签名私钥。

校园网安装页由 `tools/apk_server.py` 提供，默认端口 `8767`，提供版本化下载链接和 HTTP 分段续传。手机连接校园网后，在浏览器手动打开以下地址即可下载。当前电脑在校园网中的访问地址为 `http://10.184.17.163:8767/`；IP 改变时可在 App 的「下载 / 更新安装包」里改地址。`tools/xiaojiao-apk.service` 可作为用户级 systemd 服务常驻。升级时下载新 APK 并直接安装覆盖；不卸载旧版，手机上的课表数据会保留。首次侧载可能需要允许浏览器「安装未知应用」。

下载统计页仅允许在本机访问：`http://127.0.0.1:8767/admin`。首次访问会在 `~/.local/share/xiaojiao-timetable/admin_password` 自动生成本机私有口令；浏览器弹窗的用户名是 `admin`，密码读取该文件。统计库在同目录的 `downloads.sqlite3`，显示每个 IP 的下载次数和总次数。仅统计非本机 IP 的完整 APK 响应或续传末段；同一 IP、同一版本 30 秒内的重试合并。IP 统计不能区分共享出口的不同设备，也不能证明已经安装。管理员页面和口令不要公开分享。

安全边界：登录页限制为西交大官方 HTTPS 域名，遇到证书错误会停止连接，WebView 没有 JavaScript 到原生代码的桥接；私有课表存于应用沙盒，系统备份关闭；正式版启用 R8 混淆、资源压缩及 APK 签名。任何 APK 都不能保证不可逆向，所以程序不内置学校密码、Gemini API Key 或其他秘密；学校密码只会在用户设备上短暂解密并提交给学校官方登录页。下载服务只公开安装包、校验值和 Logo。校园网 HTTP 下载缺少服务器身份认证；首次安装请核对本目录或可信渠道提供的 SHA-256，之后 Android 会检查更新包是否由同一密钥签名。

已验证 Gradle 单元测试、Lint、正式版编译和签名；校园网完整下载与分段续传拼接后的 SHA-256 均和本地包一致。已登录教务网返回的真实课表表格能解析出 17 条课程。本机构建环境没有连接 Android 真机或模拟器，真机安装及 WebView 自动登录仍需在手机上确认。
