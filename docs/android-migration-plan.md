# StudyDesk Android 重构计划

日期：2026-09-15。执行顺序：先记录计划 → 创建公开仓库 → 编写应用及数据工具 → 验证并推送 → 配置齐全后运行模型批处理。

## 产品和交付

- 新项目名 StudyDesk，中文“学习工作台”，公开仓库拟为 CuiMiles/StudyDesk，放在当前目录的 StudyDesk/ 中；原微信项目保留。
- 面向学生手机日常使用：工作台、课表、背词、设置四个入口，模块化扩展其他学习工具。原生 Kotlin + Jetpack Compose，不使用 WebView 包装小程序。
- Android Studio Quail 4 可直接打开。固定 AGP 8.13.2、Gradle 8.13、Kotlin 2.1.20、JDK 17；compile/target SDK 36，最低 Android 8.0（API 26）。附 Gradle Wrapper、构建说明、测试及 GitHub Actions。

## 课表

- 移植北京时间、2026-09-14 开学、18 周、11 节、夏冬作息、已指定停课日、周切换、紧凑七列、连续课段合并、冲突选择及独立调课逻辑。
- 默认加入羽毛球：第 1–8 周周三第 3–4 节，2号巨构七楼羽毛球场，胡浩；首次初始化一次，不在每次启动或删除后自动重加。
- 保留课程增删改、一次调课／取消／恢复、旧小程序课表 JSON 导入与完整备份恢复。现仓库无个人手机中的已导入课表，不能假装已迁移；用户可用旧版备份迁移。
- 用户导入课表时保证指定羽毛球课可补入，并按语义检查避免重复；完整备份恢复忠实恢复内容，不暗中补课。

## IELTS Word List 和词典数据

- 只使用用户提供且已授权的 IELTS Word List.txt 作为首本书，保留原章节、顺序、原始词形、音标、中文提示和来源行号。
- 文件实际 3722 行，初步识别 3611 条词条（最终以解析报告为准）；章节标题、说明、空行不是单词。保留重复条目在书内的位置，共享规范词头学习状态；不凑成 3722 词。
- 逐词查询已经下载的官方 Open English Wordnet 2025 离线数据，相当于对同一免费词典批量查询，不逐词请求网站。原始释义、词性、例句、同义词集、来源 senseId、匹配规则存入预构建 SQLite。
- 精确匹配优先，再用显式英美拼写和连字符变体；不通过模糊匹配偷偷改词。未匹配词保留在书中、显示状态、进入报告，不能编造词典释义。
- 数据表：book、book_entry、word、sense、generation；字典只读资产与本地个人学习数据分开。保留 CC BY 4.0 署名和用户提供词表的来源说明。

## 背词与个人数据

- 单词卡英文释义优先，中文默认隐藏；支持多词义、按原书顺序学习、章节／搜索、熟词本、收藏、拼写、每日目标、到期复习及统计。
- 复习延续 1/3/7/14/30/60 天间隔，模糊次日、不认识重置且最多当轮重试两次；熟词整词跳过，可撤销或重学。提交与存储事务化，持久化会话防止旋转、重启和重复点击破坏进度。
- 内容 SQLite 随 APK 完整提供，离线可用，无远程依赖。个人状态存私有 SQLite；通过 Android 系统文件选择器导入导出 JSON，失败不覆盖，清空明确确认。不会自动上传课程和学习历史。

## 五步内容与模型接口

- 5steps_tips.txt 当前为 0 字节，需用户补全；不能把对话旧版提示词冒充该文件。框架可先完成，空提示词时批处理明确停止。
- 为每个规范词头及选定词义保留完整五步、综合示例、中文辅助、模型名、提示词 SHA-256、输入指纹、生成时间、审核状态；字典原文与模型输出独立。
- 提供 OpenAI 兼容的离线批处理 CLI：可指向本地模型或 HTTPS API；默认 dry-run，有 limit、断点续跑、重试上限、逐条原子保存和失败报告；401/403 立即停止。提示词及结构校验通过后才写入 generation 表。
- 六段内容强制完整：具体画面、至少三个近义词对比、语域及 1–2 个语境、2–3 个搭配及语义韵、至少三个联想概念、50–100 英文词综合示例及对应说明。输出缺失／JSON 非法／引用词义错误不得标记完成。
- 运行生成前还缺接口地址、模型名和凭据环境变量配置；这些作为外部输入阻塞，不影响 Android 实现。批处理在框架完成后调用，不在开发早期擅自批量计费。
- 手机问答保留可替换 provider 接口，默认未接入；用户可复制问题及当前词义。私有 API key 不打包、不推送，未来手机联网问答使用自有后端。

## 验证与完成标准

- Python：词表解析、重复及未匹配报告、SQLite 完整性、来源追溯、模型输出校验、断点续跑、认证失败停止。
- Kotlin 单元测试：日期与羽毛球八周实例、假日、跨周调课、连堂合并、冲突、复习间隔、重试／重复提交／跨日、备份校验。
- 尽可能实际运行 assembleDebug 和测试；不能运行的工具链或真机检查如实报告。CI 独立构建并产出调试 APK。
- 用户在 Android Studio Quail 4 导入新仓库，选择 Gradle JDK 17 或兼容的新 JDK，安装 SDK 36，运行手机验证。没有实际执行的真机测试、模型生成和应用发布不写成已完成。
