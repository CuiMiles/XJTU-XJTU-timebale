# 小交课表 V1

面向西安交通大学学生的轻量个人课表。原生微信小程序，TypeScript 源码，浅色七列周视图。**非官方产品，不使用学校 Logo**。无服务器、云开发、登录、第三方 API 或 AI 调用；课程和调课只存微信本地 Storage。

## Windows 直接打开

1. 克隆本仓库，在微信开发者工具中选择「导入项目」，目录选择仓库根目录（包含 `project.config.json` 的目录）。
2. 项目已设置 `miniprogramRoot: miniprogram/`，默认 `touristappid`，使用工具的「测试号/无 AppID」本地调试方式。不使用云服务。若当前工具要求有效 AppID，可填写自己的小程序测试 AppID。
3. 点击「编译」。**运行不需要安装 Node、不需要 npm install、不需要构建 npm**：编译后的 `.js` 已随仓库提交，开发者工具直接使用这些文件。`.ts` 是维护用源码，未开启工具的 TypeScript 编译插件，避免重复编译。
4. 初次进入是空状态。点击「导入课表 → 填入示例 JSON → 校验并预览 → 确认导入」。示例课在第1～8周星期六第1～2节。日期尚未开学时默认展示第1周。
5. 真机预览、文件分享等能力可能需要自己的 AppID 和开发者身份；测试号的模拟器不等同于真机验证。

## 使用

- 首页始终七列（周一到周日）、1～11节，课程跨节显示；点击左上角周选择器或左右滑动课表切换1～18周，点击「今天周X · 本周/非本周」回到实际周。左上角显示周次，表格角标显示所选周周一所属月份，表头日期只显示日数字，跨月的1日额外标记月份。顶部保留“2026-2027秋 · 第一学期”，使用自定义导航避开系统居中标题。学期外显示最近的学期边界周。
- 卡片只突出名称、教室，颜色由课程名稳定生成。点击弹出详情，显示当天时间、班级、教师、周次和备注。重叠课程显示提示，点击可选择全部重叠课程；不连续节次拆成多个卡片。三节及更多连续节次完整跨格；同一天课程名、教室、班级、教师等相同的连续课段合并成一张卡片（教师顺序、空格和周次列表差异不妨碍当天连堂显示）。详情将连续节次和时间合并为范围；合并卡片若包含多条基础课程，调整时选择对应课段，基础数据与独立调整身份保持不变。
- 「管理」中新增/编辑/删除课程。周次可以逐一勾选，支持单周、双周、周末、考试周。同一时段不同周的课程分别录入即可。
- 在详情里「调整本次」修改日期、节次、教室或取消；只修改这一次，不影响其他周。调整目标限定本学期。主动安排到停课日会确认后显示。
- 「管理 → 查看某一次」可以打开被停课规则隐藏的课程或已取消课程，安排补课。调整记录提供「恢复原安排」。编辑基础课程若已有调整，会明确确认并清除该课程的调整，避免悬空数据。
- 「管理 → 备份与恢复」复制完整 JSON 到自己的文件，或分享 `.json` 文件；将备份粘贴回去、校验预览、确认后恢复。复制成功不代表已保存到设备外，请自行保管导出文件。
- 导入和恢复均为**整体替换**，操作前确认；不是追加合并。清空数据必须连续两次确认。
- 存储损坏时不会自动覆盖原数据，管理页可复制原始数据留存，再恢复有效备份。存储写入失败会提示，不报告成功。卸载、清缓存、换机不会自动迁移，请先备份。

## 课表导入格式

```json
{
  "schemaVersion": 1,
  "semesterId": "2026-fall",
  "courses": [
    {
      "name": "数据库系统原理与应用",
      "className": "1班",
      "teachers": ["刘帅"],
      "room": "5-2W201",
      "weekday": 6,
      "sections": [1, 2],
      "weeks": [1, 2, 3, 4, 5, 6, 7, 8],
      "note": ""
    }
  ]
}
```

所有示例字段必填。课程名非空；班级、教室、备注可填空字符串；教师未知填 `[]`。文本最长500字，教师最多20项。`weekday` 为整数1～7（周一到周日），`sections` 为1～11的不重复非空整数数组，`weeks` 为1～18的不重复非空整数数组；顺序可乱，导入自动排序。不自动猜测或修复错误类型，不接受字符串数字。最多500条课程，JSON最多200万字符。空 `courses` 可校验，但确认导入会清空当前课表。多星期/不同教室或周次组合应拆成独立条目。

AI 转换提示词可在导入页一键复制，源文件 `miniprogram/core/prompt.ts`。小程序从不向 AI 发送内容。请核对 AI 结果后再确认导入。

## 完整备份与调课模型

完整备份在上述顶层增加 `backupVersion: 1`、`adjustments: []`，每条课程增加唯一 `id`。普通导入自动生成 ID；恢复备份原样保留 ID，严格检查调课关联、原日期、范围和重复记录。

一条调整示例（`courseId` 必须对应备份内实际课程，且原日期必须属于其循环安排）：

```json
{
  "courseId": "实际课程ID",
  "originalDate": "2026-09-19",
  "cancelled": false,
  "date": "2026-09-22",
  "sections": [3, 4],
  "room": "5-2W202"
}
```

`courseId + originalDate` 唯一定位“这一周这一堂课”。同一条基础课程的当日全部节次作为一次处理；如需独立调整上午/下午两堂，请将基础课程拆成两条。引擎枚举原始发生日期，再应用调整，然后按目标周过滤，因此支持跨周移动。取消记录仍保留完整字段；恢复原安排只删除对应调整。备份最多10000条调整。

## 学期与时间

- 按需求指定：第1周周一 **2026-09-14**；第1～16周教学，第17～18周考试；第18周周日 **2027-01-17**。考试周不会自动生成考试，只显示显式选择这些周的课程。
- 停课日：2026-09-25、2026-10-01～03、2027-01-01。普通循环课仅隐藏发生实例，不删基础数据；不擅自增加国家调休日或推测补课。
- 固定使用北京时间（UTC+8）识别今天与当前教学周，不受设备时区影响；日历运算使用 UTC 日期整数，避免日期字符串解析、夏令时造成偏移。
- 节次配置、日期计算统一在 `core/calendar.ts`。5月1日至9月30日使用夏秋作息，10月1日起使用冬春作息。第3周跨作息切换，左侧按周一时间显示并提示，详情按课程实际日期显示准确时间。
- 默认节次依据学校2025年公开的[冬春作息通知及时间表](https://gs.xjtu.edu.cn/info/1146/11078.htm)和[夏秋作息通知及时间表](https://gs.xjtu.edu.cn/info/1146/10720.htm)。2026年若学校另行调整，请集中修改配置；2026学期起点和停课日使用本项目指定值。

## 代码结构与维护

```text
miniprogram/
  app.*                 应用与通用样式
  core/
    calendar.ts         学期、停课日、日期与节次时间
    types.ts            课程、单次调整、存储类型
    engine.ts           周课表引擎、颜色、跨节卡片
    validation.ts       导入/备份/手动输入校验
    storage.ts          本地读写、错误提示
    prompt.ts           AI 提示词与导入示例
  pages/
    home/               干净周视图、详情弹层、冲突选择
    manage/             课程管理、调整记录、清空
    editor/             手动新增/编辑
    detail/             单次调整与恢复
    transfer/           导入预览、备份恢复
 tests/                 核心逻辑与页面绑定检查
```

维护源码需 Node.js 18+：

```sh
npm ci
npm run check
npm test
```

修改 `.ts` 后执行 `npm run build`，同时提交生成的 `.js`。没有运行时 npm 依赖。`npm test` 包含编译、日期/假期/调课/校验/Storage 模拟测试及页面路由和事件引用检查。

## 验证边界和开发者工具验收

Linux 已执行 TypeScript 检查、自动化测试、路由/事件绑定静态检查。这里没有运行微信开发者工具，不能保证 WXML/WXSS 的实际渲染和平台接口已通过真机验证。

建议在 Windows 工具依次检查：

1. 空状态、七列小屏排版、滚动至第11节、跨节圆角卡片、详情弹层关闭与滚动。
2. 示例导入第1周周六，新增周日课、不连续周次、两个完全重叠课程，确认都可查看。
3. 第2周周五9/25、第3周10/1～3、第16周1/1普通课隐藏，管理页仍能找到基础课。
4. 第1周课移动到第2周、改教室、取消、恢复；下一周原课保持不变。
5. 导出备份，清空时取消第二次确认，确认数据保留；真正清空后恢复，核对课程和调整记录。
6. 非法 JSON、缺失字段、重复节次、错误周次、无效备份不导致白屏；重启小程序数据保留。
7. 剪贴板、JSON文件分享、键盘遮挡、日期选择器、窄屏与真机安全区。模拟器文件分享失败时可使用复制JSON。
